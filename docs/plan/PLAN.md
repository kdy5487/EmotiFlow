- 다크모드 완성

- 라우팅 버그: AI 채팅 일기 → 상세 페이지 연결 이슈
- 프로필 편집 페이지

## 아키텍처 결정사항 (ADR)

| 결정 | 이유 |
|------|------|
| Riverpod (AsyncNotifier) | Provider보다 타입 안전성, 테스트 용이 |
| GoRouter | 딥링크 지원, 선언적 라우팅 |
