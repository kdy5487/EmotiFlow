## Phase 3 - AI 경험 고도화

**목표**: 타 감정 일기 앱과의 차별화

### AI 캐릭터 NPC 시스템
- 3~5종 캐릭터 (따뜻한/직설적인/유쾌한/차분한)
- 세션 시작 시 캐릭터 선택, 대화 중 교체 가능
- 캐릭터별 고유 프롬프트 (말투/이모지 스타일)

### 질문 던전 모드
- 한 턴에 3~5개 질문 카드 제시
- 카드 난이도 (가벼움/보통/깊음) 표시
- 선택에 따라 분기되는 후속 질문 트리

### 감정 시각화 고도화
- **감정 레이어 캘린더**: 하루 감정을 '층'으로 쌓아 색/투명도로 표현
- **감정 스펙트럼 링**: 일간 감정 원형 비율 시각화
- **감정 성장 그래프**: 기록할수록 성장하는 식물/결정체 비유

### 감정 회고 카드
- 대화 기반 '오늘의 한 문장' 자동 생성
- 공유 가능한 카드 이미지 출력
